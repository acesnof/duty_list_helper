Duty List Helper

User manual for configuring personnel, producing and validating the duty forecast, managing duty changes and protecting the local database.

Standalone applicationThe complete application runs from one HTML file in a modern browser.
Local protectionData and the ten newest automatic snapshots remain in browser storage.
Two roster modesUse one continuous rotation or independent normal/day-off rotations.

1. Starting and closing the application

The application runs locally inside a modern web browser.

  1. Open Duty List Helper.html in Microsoft Edge, Google Chrome or Firefox.
  2. The Dashboard opens immediately. No server, installation or Internet connection is required.
  3. Use the Protected button and administration code 1234 before changing application data.
  4. When finished, simply close the browser tab.
The HTML file contains the application, fonts, images, flags, document templates and export engines. Keep a JSON backup when moving data to another computer or browser profile.

2. Dashboard

The Dashboard gives the scheduler a compact operational picture.

  • Available today: active personnel currently eligible for duty.
  • Unavailable today: personnel affected by holidays, exemptions or mission buffers.
  • Week coverage: how many days in the current week have an assigned Duty Officer.
  • Validated this week: how many days have been formally confirmed.
  • Current week: the assigned officer, day category and status for each day.
  • Next 30 days: relevant days off, arrivals, departures, holidays, exemptions and duty changes.

Select Open Duty List to go directly to the calendar.

3. Personnel administration

Use Personnel to maintain every person who may appear in the roster.

Adding or editing personnel

  • Select Add person, or use Edit on an existing record.
  • Complete nationality, rank, date of rank, first name, last name, position number, arrival date and departure date. The Position field is optional.
  • Names are stored in uppercase for consistent documents and calendar display.
  • Arrival, rank, date of rank and name are used as tie-breakers when there is no previous duty reference.

Current and historical personnel

The default view shows current and incoming personnel. Select Show all to include personnel who have already departed. Personnel are unavailable before arrival and after departure.

Delete a person only when the record is genuinely no longer required. Existing assignments or exemptions may prevent deletion to protect roster integrity.

4. Duty Exemptions

Duty Exemptions prevent a person from being selected by the automatic forecast.

Holidays

Enter the first and last actual holiday day. The application also applies the configured exemption days before and after the holiday period. Actual holidays appear yellow; the surrounding exemption period appears pale yellow.

Other exemptions

Use Other for another authorised period in which the person cannot perform duty. Add a clear observation when useful.

SOM and EOM

Start of Mission (SOM) and End of Mission (EOM) exemptions are calculated automatically from the personnel arrival and departure dates and the values in Duty Service Settings.

5. Duty List calendar

The calendar shows the current month and the following month, with one row per person.

  • Saturdays remain orange and Sundays or registered days off remain red.
  • Cells outside a person's mission period retain a lighter version of the day colour.
  • An assigned service is represented by a large X.
  • A green duty cell identifies a service involved in an approved duty change.
  • Hover over a personnel row to follow it across the calendar.

Manual assignments

  1. Select an available cell to add or move an assignment for that day.
  2. A small confirmation panel appears only while there are pending changes.
  3. Select Confirm to save the changes or Cancel to discard them.
  4. Select the same changed cell again before confirming to undo that pending change.

Validating a day

Use the checkbox above a date to validate or unvalidate that day. A validated column becomes light grey. Validated assignments are treated as confirmed and are preserved when the automatic forecast is recalculated.

6. Forecast modes and controls

The active mode is selected in Lists & Settings → Duty Service Settings.

Duty List - All daysOne continuous rotation covers every calendar day. Weekdays, Saturdays, Sundays and official days off all advance the same list. This is the default mode.
Duty List - 2 List - Normal and Day OffMaintains two independent histories: normal services and Sunday/official day-off services. Day-off duties take priority when preventing consecutive services.

Update forecast

Calculates automatic assignments after the last validated day for the displayed period. The most rested available person in the applicable rotation is selected first.

Clean forecast

Removes automatic forecast assignments after the last validated day. Validated days, confirmed manual assignments and duty changes are preserved.

Changing the mode

Saving a different roster mode automatically clears and rebuilds the future automatic forecast after the last validated day. Confirmed information is not removed.

Duty Order

Shows personnel from most rested to least rested, including the last duty date and current availability observations. All-days mode shows one list; two-list mode shows Normal Days and Sundays/Days Off separately.

7. Duty Changes

Use Changes to exchange an already confirmed service between two people.

  1. Select a duty date. Only a validated service can be changed.
  2. The application identifies the currently assigned Duty Officer.
  3. Select the replacement. The original officer takes the replacement person's next eligible service opportunity.
  4. Select Create change. Both exchanged duty cells are shown in green.

In two-list mode, both services must belong to the same roster type. In all-days mode, any future service in the continuous rotation may be used. Current and upcoming changes are listed by nearest date; See all also shows historical changes. Use the delete control to cancel a change and restore both original assignments.

8. Documents and exports

Rules document

Open Rules of Duty List and select Print to export the current rules and Duty Service Settings to a compact, one-page A4 portrait Word document.

Export Week

Each complete Monday-to-Sunday block has an Export Week button. One aligned table contains Monday through Sunday, two blank separator rows, and the following Monday, Tuesday and Wednesday.

  • Enter a document number to replace NUMBER, or leave it blank to keep the placeholder.
  • Select AMEDMENT when the amendment indication must appear below the period.
  • The configured COS rank and name are inserted automatically.
  • The file name includes the creation date and the duty-list period.

Full Export

Creates a self-contained A3 PDF representation of the two visible calendar months, preserving full personnel names, duty marks, exemptions, validated days and day colours. No browser or additional PDF software is required.

9. Days Off Manager

Register public holidays and other officially designated non-working days.

  • Select Add day off and enter its name, date and optional observations.
  • Registered days are displayed as red day-off columns in the calendar.
  • In two-list mode they belong to the special rotation, like Sundays.
  • In all-days mode the colour remains for operational context, but the day belongs to the single continuous rotation.

10. Lists & Settings

Chief of Staff (COS)

Configure the rank and full name used in exported weekly duty-list documents.

Duty Service Settings

  • Select the active duty-list mode.
  • Define exemption days before and after holidays.
  • Define SOM exemption days from mission arrival.
  • Define EOM exemption days before mission departure.

Nationalities and ranks

Add or edit the reference lists available in Personnel. Use two-letter nationality codes so the corresponding flag can be displayed. Delete reference values only when they are not being used by personnel records.

11. Backup and restore

Application data is stored locally by the browser. Nothing is transmitted to an external service.

Automatic snapshots

  • Opening the application records a local snapshot of the current data.
  • The ten newest snapshots are retained in the same browser profile.
  • Browser snapshots protect normal work but do not travel with the HTML file.

Portable backup

  1. Open Lists & Settings.
  2. Select Export backup to download a JSON file.
  3. Copy the HTML application and JSON backup to the destination computer.
  4. Open the application, unlock editing and select Import backup.
  5. Select the JSON file and verify the restored information.
Important: importing a backup replaces the current browser data. Export the current data first if it may still be required.

12. Main calculation rules

  1. The available person who performed duty longest ago in the active rotation is selected first.
  2. A person cannot perform duty on consecutive days.
  3. Holidays, holiday buffers, SOM, EOM, other exemptions and time outside the mission period make a person unavailable.
  4. When there is no previous duty reference, priority is: earliest mission arrival, lowest rank, earliest date of rank and alphabetical name.
  5. In two-list mode, normal and Sunday/day-off duty histories are independent, and a day-off duty has priority over a conflicting normal duty.
  6. Validated days are fixed. Future automatic appointments are recalculated after the latest validated day.

Select Rules of Duty List in the calendar for the complete operational replacement policy and the current configuration values.

13. Troubleshooting

The application does not open

Open Duty List Helper.html with an up-to-date Microsoft Edge, Google Chrome or Firefox browser.

A forecast day is missing

Check whether any person is available on that date, confirm personnel mission dates and exemptions, then select Update forecast.

A cell cannot be changed

Unlock editing first. Validated days must be unvalidated before changes, and personnel cannot be assigned during an unavailable period.

A weekly document cannot be generated

Confirm that all ten required duty days have an assigned person. The original Word template is embedded in the HTML file.

The A3 PDF cannot be generated

Allow the browser to download files and try again. The A3 PDF engine and print fonts are embedded locally.

The application does not require Python, executables, libraries, a server or Internet access. All processing remains inside the browser.
